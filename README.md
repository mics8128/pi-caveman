# pi-caveman

Pi extension for Caveman full mode.

## Features

- Session-wide Caveman full rules injected once per session
- Short per-turn reminder injected every prompt
- `/caveman-compress <filepath>` command for compressing natural-language memory files
- `/caveman:compress <filepath>` alias
- No footer/status badge

## Commands

```txt
/pi-caveman on
/pi-caveman off
/pi-caveman status
/caveman-compress <filepath>
/caveman:compress <filepath>
```

Compatibility aliases:

```txt
/caveman-session on|off|status
/caveman-smart on|off|status
```

## Reload

```txt
/reload
```
